# SB22 Agency — PHP hosting
The PHP portfolio needs a PHP 8.2+ hosting provider, such as InfinityFree or alwaysdata Plus.
Extract the ZIP on your computer and upload its contents to the public web directory (htdocs for InfinityFree). Keep index.php at the root.
The five projects are stored in data/projects, loaded by functions/projects.php and rendered by includes/project-card.php.
The project pages, media and filters remain dynamic PHP and JavaScript.
The contact form is a demonstration and does not send messages. Configure and test email delivery separately before using the site for production.
This PHP version is maintained separately from the static HTML reference under maquettes/version-b.
