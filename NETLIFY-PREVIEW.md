# Prévisualisation Netlify

Cette branche produit automatiquement une prévisualisation statique lors des tests GitHub Actions.

Télécharger l’archive « SB22-Portfolio-Netlify-Preview » depuis l’exécution réussie du workflow. Elle contient « sb22-portfolio-feedback.zip », à déposer sur Netlify.

L’export comporte la page d’accueil, quatre pages d’agence/navigation et cinq pages de réalisations avec leurs images et vidéos.

Les sources PHP restent disponibles dans cette branche. L’archive HTML est une maquette et ne traite pas l’envoi réel des formulaires.

La mise en ligne doit être effectuée sur un site de prévisualisation distinct des versions A/B déjà envoyées, jusqu’à la validation.
